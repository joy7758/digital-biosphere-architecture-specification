# Value-Gate Remediation Roadmap

The frozen five-task fixture records high noise (`0.88`) and zero final outcome
improvement. Those results are retained; changing the numbers would destroy the
evidence.

Before `agent_operational_value_demonstrated` can become true, a separately
authorized pilot must:

1. define representative tasks and a pre-registered outcome measure;
2. measure reason-code precision and attention cost;
3. reduce false/not-applicable and duplicate findings without hiding them;
4. demonstrate at least one reproducible outcome improvement;
5. repeat across more than one independent model lineage;
6. preserve negative and `NOT_ASSESSED` results.

The current human-intervention rate is `0.0833`. The `0.01` value remains a
long-term target, not a v1.1 acceptance gate or current claim.

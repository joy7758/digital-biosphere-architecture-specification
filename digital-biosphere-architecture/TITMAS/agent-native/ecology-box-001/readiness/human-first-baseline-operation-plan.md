# Human-first Baseline Operation Plan v0.1

This readiness supplement does not alter the frozen
[`baseline-execution-plan.md`](../baseline-execution-plan.md).

```text
RECOMMENDED_BASELINE_TYPE=PROSPECTIVE_MATCHED
BASELINE_TYPE_DECIDED=false
HUMAN_BASELINE_OPERATOR_ASSIGNED=false
EXECUTION_AUTHORIZED=false
```

`HD-EB-12` must select the baseline type. Historical work cannot automatically
become a prospective matched baseline. A separately accepted archival baseline
must state `BASELINE_TYPE=ARCHIVAL` and `EVIDENCE_STRENGTH=LOWER`.

The operator must disclose prior familiarity; remain separate from the blind
Reviewer and blind custodian; use the same ten tasks, source, inputs, outputs,
rubric and blind evaluation; and record time, clarification, review, rework and
validation counts.

Allowed tools are an offline editor, frozen local source search and frozen
deterministic tests. Ordinary network search and AI assistance are prohibited.
Observed AI assistance stops the task as a protocol deviation.

Final packaging contains only the origin-neutral candidate, declared source
references, time/action receipts, validation output, failures, abstentions and
limitations.

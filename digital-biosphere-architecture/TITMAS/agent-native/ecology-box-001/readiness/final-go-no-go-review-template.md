assignment, adoption or authorization from the readiness package.

## Deterministic result

```text
all_blocking_prerequisites_satisfied=
human_execution_decision_accept=
GO_NO_GO_STATUS=
GO_NO_GO_REASON=
```

Allowed results are `GO` or `NO_GO`. `GO` requires every blocking prerequisite
to be `SATISFIED` and a non-expired explicit Human authorization.

## Required signatures

- Accountable Human Owner;
- independent Reviewer boundary check;
- blind custodian custody acceptance;
- Provider/privacy owner adoption receipt;
- Emergency Stop Authority acceptance.

`NO_GO` is a readiness outcome, not an experiment failure. The template cannot
record an experiment result, value proof, Release or commercial claim.

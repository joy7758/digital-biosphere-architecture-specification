# Runs

This directory is reserved for future, separately authorized run records that
conform to the existing
`TITMAS/agent-native/schemas/value-validation-experiment-record.schema.json`.

```text
RUN_RECORD_COUNT=0
EXPERIMENT_EXECUTED=false
EXECUTION_AUTHORIZED=false
```

Do not place synthetic examples here because their presence could be confused
with execution. The existing `NOT_EXECUTED` example remains under
`TITMAS/agent-native/value-validation/`.

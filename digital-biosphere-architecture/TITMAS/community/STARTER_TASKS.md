# TITMAS Starter Tasks

The sole canonical machine task registry is:

[`../agent-native/tasks/task-registry.json`](../agent-native/tasks/task-registry.json)

This page is a human compatibility pointer, not a second registry. Tasks are
prepared Development records, not GitHub Issues, assignments, permissions or
public contribution authorization.

Use the agent-native CLI to discover a bounded task:

```bash
python3 TITMAS/agent-native/community_cli.py discover \
  --need "machine-readable evidence review"
```

Every task remains bounded by `Evidence != Truth`,
`Verification != Authorization`, `Mapping != Adoption`,
`Agent Review != Human Authority` and
`Reference Implementation != Standard Authority`.

# Dormant GitHub Contribution Templates

Status: `DORMANT_ACTIVATION_PACKAGE`

These TITMAS Issue Forms and Pull Request template have been developed and
structurally validated. They are intentionally stored outside `.github`, so
GitHub does not install or expose them as a public contribution surface.

Current boundaries:

1. the templates are developed but not installed;
2. this directory is not a public Issue or Pull Request contribution surface;
3. manual copying does not create authorization;
4. installation requires a separate Human Decision;
5. installation requires an active, verified private Security Transport;
6. installation must use an independent Activation PR;
7. the Activation PR must not be combined with specification-mainline work;
8. template hashes must match [`activation-manifest.json`](activation-manifest.json);
9. installation does not establish the TITMAS community;
10. installation does not authorize or perform a public launch.

Prepared activation gates:

- [Security Transport Activation Checklist](SECURITY-TRANSPORT-ACTIVATION-CHECKLIST.md)
- [Public Contribution Activation Checklist](PUBLIC-CONTRIBUTION-ACTIVATION-CHECKLIST.md)

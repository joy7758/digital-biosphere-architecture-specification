# Security Transport Activation Checklist

Status: `NOT_EXECUTED`

This checklist prepares a future, separate Human Decision. It does not change
repository settings or activate a receiving route.

| Check | Initial state |
|---|---|
| Human Decision ID recorded | `NOT_EXECUTED` |
| GitHub Private Vulnerability Reporting enabled | `NOT_EXECUTED` |
| Security Process Owner term valid | `NOT_EXECUTED` |
| Private intake reachable by an authorized reporter | `NOT_EXECUTED` |
| Synthetic private test report received | `NOT_EXECUTED` |
| Notification and acknowledgement confirmed | `NOT_EXECUTED` |
| Response-time statement reviewed | `NOT_EXECUTED` |
| Data retention and deletion rules approved | `NOT_EXECUTED` |
| Emergency disable procedure reviewed | `NOT_EXECUTED` |
| Public `SECURITY.md` route verified | `NOT_EXECUTED` |
| Public-Issue sensitive disclosure warning verified | `NOT_EXECUTED` |
| Rollback steps verified | `NOT_EXECUTED` |

Required evidence must include the decision reference, observer, timestamp,
actual private test receipt, access boundary and rollback result. A configured
process or assigned owner is not evidence that the transport is active.

```text
SECURITY_PROCESS_NE_SECURITY_TRANSPORT=true
SECURITY_SETTING_CHANGE_AUTHORIZED=false
SECURITY_TRANSPORT_ACTIVE=false
```

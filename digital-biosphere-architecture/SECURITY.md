# Security

Read the prepared security policy at
[TITMAS/community/SECURITY.md](TITMAS/community/SECURITY.md).

Do not disclose secrets, personal data or vulnerability details in a public
Issue. GitHub Private Vulnerability Reporting was enabled and verified through
the repository API on 2026-07-29. Use the private **Report a vulnerability**
entry under the repository Security / Advisories area. The temporary process
owner is `zhangbin` through
2026-09-30T23:59:59+08:00; this assignment is routing responsibility, not
Security Certification Authority.

The TITMAS Issue and Pull Request templates are installed only on the
Activation PR branch and remain inactive until merge. Public Issues must never
be used as a substitute for the private security intake. No SLA, security
audit, certification or zero-vulnerability claim is made.

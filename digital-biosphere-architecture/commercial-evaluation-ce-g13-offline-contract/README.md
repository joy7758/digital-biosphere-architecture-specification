# TITMAS CE-G13 Offline Execution Contract Package v0.1

This Development package freezes the inputs required to evaluate whether isolated AI-agent
customer roles can discover TITMAS from the public website and produce a bounded reuse plan.

It is not CE-G13 execution, a Runtime, an Agent, a customer, adoption, a commercial offering,
certification or production evidence.

```text
PACKAGE_STATUS=OFFLINE_CONTRACT_PACKAGE_CANDIDATE_NOT_EXECUTED
PUBLIC_FETCHES=0
MODEL_REQUESTS=0
TECHNICAL_REUSE_RUNS=0
CUSTOMER_ADOPTION_VERIFIED=false
COMMERCIAL_OFFERING=false
PRODUCTION_READY=false
```

The package contains 21 JSON files, two Markdown files and five immutable prompt files. The package
manifest hashes every file except itself under a declared non-recursive rule.

Future execution requires a separate Human Decision after this package passes offline validation.
